# Market Day Register

A React + Supabase register app for classroom student businesses.
See the setup guide provided alongside this project for step-by-step
instructions with no coding experience required.

## Local development (optional, for teachers who do want to run it on their own computer)
1. Copy `.env.example` to `.env` and fill in your Supabase project URL and anon key.
2. `npm install`
3. `npm run dev`
